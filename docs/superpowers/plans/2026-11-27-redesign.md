# Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans.

**Goal:** Restyle every screen in the approved mixed style and add stock charts and rank progress.

**Architecture:** `styles.css` owns all styling. `index.html` holds structure and an inline icon sprite. `ui.js`
renders with component classes. Two small rule additions live in `logic.js`.

**Spec:** `docs/superpowers/specs/2026-11-27-redesign-design.md`

## Global Constraints
- Element ids used by tests and logic do not change. No commits unless asked.

## Review Focus
- Old save without price history: chart draws and percentage reads 0.
- Top rank: progress bar full, no "next rank" text.
- Very large balances and long names on a 360px screen: no sideways scrolling.
- Fonts or network unavailable: readable and usable.
- Reduced motion: cards and results still appear.
