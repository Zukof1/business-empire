# Backup and Home Screen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Back up and restore the game, ask for protected storage, and add a Home Screen icon.

**Spec:** `docs/superpowers/specs/2026-11-27-backup-design.md`

## Global Constraints
- No new script files. Bump `?v=` to 21. Tapped things are at least 44px. No commits unless asked.

## Review Focus
- Code pasted with spaces or line breaks added by a notes app: still restores.
- Half a code, other text, or an empty box: nothing changes.
- Autosave firing, or the page closing, between restore and reload: the restored save survives.
- Storage full during restore: the current game is kept and the player is told.
- Text boxes can be selected and pasted into, although the page turns selection off.
